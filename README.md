# Evolution of cooperation in indirect reciprocity with costly information

This repository contains the simulation code for the manuscript by Zhenghan Yan and Bin Wu.

## Repository structure

| Path | Contents |
| --- | --- |
| `src/`, `env2/`, `env3/` | Finite-mutation C++ simulations for Environments 1, 2, and 3, respectively. Each environment has its own `CMakeLists.txt`. |
| `fixation_mutation/` | C++ simulations for the small-mutation limit, organized into `env1/`, `env2/`, and `env3/`. |
| `reproduce.sh` | Script for building and running the simulations. |
| `plot_compare_env_no_welfare.py`, `requirements.txt` | Figure-generation script and its Python dependency. |
| [`figures/mu.pdf`](figures/mu.pdf) | Original manuscript figure on discriminator abundance across mutation rates. |
| [`data/simulation_summary.csv`](data/simulation_summary.csv) | Archived database summaries for the two discriminator strategies in each environment. |

## Simulation purpose

The simulations support the manuscript's **Mutation rate** subsection. They test whether the combined abundance of the two discriminator strategies, `DIS` and `DIS_TILDE`, and its ordering across the three strategic environments depend on the mutation rate. The finite-mutation runs allow several strategies to coexist. The fixation runs provide a comparison at the small-mutation limit.

## Simulation steps

1. **Initialize the population.** Each run starts with `N = 100` individuals divided equally among the four strategies defined for that environment. The manuscript settings use donation benefit `b = 5`, cooperation cost `c = 1`, reputation recognition probability `q = 0.3`, recognition increment `delta_q = 0.3`, and information cost `p = 0.1`.
2. **Play the donation games.** At the start of each generation, all reputations are set to Good and payoffs are reset to zero. The interaction stage uses the expected number of rounds, `1/(1-w)`, for a continuation probability of `w = 0.98`. In each round, individuals are randomly paired, with one randomly chosen donor per pair. Donors act according to their strategies. Image Scoring assigns a Good reputation after cooperation and a Bad reputation after defection. At the end of the interaction stage, the program computes each individual's average payoff per round.
3. **Update strategies at finite mutation rates.** For each of 13 nominal mutation rates `mu` from `1e-4` to `1`, one randomly chosen individual has a chance to change strategy per generation. Every `tau = round(1/mu)` updates, that individual mutates to one of the other three strategies chosen uniformly. On other updates, it can copy a randomly selected peer under the Fermi rule with `beta = 0.0003`. The program discards the first `max(10000, 50*tau)` generations and averages the strategy frequencies over the next `max(100000, 30*N*tau)` generations.
4. **Estimate the small-mutation limit.** Once the population consists of a single strategy, the fixation program introduces one mutant. Fermi imitation then continues until the mutant takes over or dies out. Each run records 1,200 successful mutant takeovers and computes the share attributable to each strategy.
5. **Summarize the runs.** The full protocol uses 512 independent runs per environment and mutation rate, and 512 per environment for the fixation estimates. The figure plots the sum of the two discriminator abundances as curves for finite mutation rates and diamonds for the fixation estimates. The plotting script uses saved manuscript values by default. Its `--runs-dir` option plots the summaries generated by `reproduce.sh full`.
